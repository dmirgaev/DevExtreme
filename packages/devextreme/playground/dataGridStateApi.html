DataGrid State API


ℹ️ Hybrid actions

Most actions work exclusively through grid.state(newState). A few actions require a hybrid approach — either reading runtime information before writing through state, or bypassing state entirely:

  • selectByIndexes — state() stores selectedRowKeys (by key), not by visible row index. Workaround: read grid.getVisibleRows() to resolve indexes → keys, then write those keys into state.selectedRowKeys.
  • selectAll — state() stores an explicit selectedRowKeys array; there is no state-only way to express "all rows selected". Workaround: read all records from the underlying store via grid.getDataSource().store().load(), extract every key, then write them into state.selectedRowKeys. For large remote data sets this loads the full data set to the client.
  • summary / clearSummary — Summary configuration is not part of grid.state(). Workaround: read/write through grid.option('summary', …). This is a full hybrid: both read and write bypass state.

No option(), columnOption(), or mutating imperative methods (selectRows, clearSorting, etc.) are used anywhere — except for the hybrid actions listed above.
